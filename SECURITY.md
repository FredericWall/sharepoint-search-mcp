# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting feature for this repository. If that feature is not
available, contact the repository owner privately.

Do not include real access tokens, passwords, client secrets, service keys, personal
data, or document content in a report. Revoke and rotate any credential that may have
been exposed.

## Supported versions

Security fixes are applied to the latest revision on the main branch. This project is
a reference implementation; operators remain responsible for identity-provider,
network, database, retention, backup, and access-control configuration.
