# Contributing

Issues and pull requests are welcome. Before proposing a change:

1. Do not include SharePoint documents, generated indexes, model weights, credentials,
   tokens, personal information, private tenant URLs, or service-binding data.
2. Keep indexer and mcp_server independently deployable.
3. Add or update tests for behavioral changes.
4. Run the local checks documented in README.md.

By submitting a contribution, you agree that it is licensed under Apache-2.0, the
license of this repository, and confirm that you have the right to submit it.
